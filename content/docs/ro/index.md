# Documentație Wildfire

Bine ați venit pe platforma de documentație **Wildfire Docs**. Acest motor modern de documentare este conceput pentru dezvoltatori exigenți, oferind sincronizare Git în timp real, design liquid glass și performanțe maxime de randare.

<Callout type="info" title="Sincronizare Automată Git">
Fiecare pagină din acest portal este sincronizată automat cu depozitul GitHub. Ultima modificare și autorul sunt extrase direct din istoricul commit-urilor.
</Callout>

## Arhitectură Tehnică

Platforma folosește cele mai noi standarde web:

- **Next.js 16 cu Turbopack**: Generare statică ultrarapidă (SSG) și revalidare incrementală (ISR).
- **Stilizare Liquid Glass**: Design rafinat cu accente ember, efecte de sticlă mată și fluiditate pe dispozitive mobile.
- **Căutare CmdK Indexată**: Motor de căutare instantanee direct în antet cu filtrare bilingvă.
- **Suport Bilingv Nativ**: Comutare instantanee între **Română (🇷🇴)** și **Engleză (🇬🇧)**.
