# Structură Schemă

Fiecare fișier de documentație acceptă un antet YAML (frontmatter) standardizat:

```yaml
---
title: "Titlul Paginii"
description: "Descriere concisă pentru SEO și carduri de sumar."
order: 1
badge: "v1.0"
seoTitle: "Titlu Personalizat pentru Tab"
seoDescription: "Descriere OpenGraph extinsă"
showToc: true
showFeedback: true
---
```
