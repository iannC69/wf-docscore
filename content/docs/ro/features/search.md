# Căutare Instantanee CmdK

Wildfire Docs include un motor de căutare bilingv indexat la momentul compilării și revalidării.

## Scurtături de Tastatură

- <kbd>Ctrl K</kbd> sau <kbd>⌘K</kbd>: Deschide dialogul de căutare.
- <kbd>↑</kbd> / <kbd>↓</kbd>: Navighează între rezultate.
- <kbd>Enter</kbd>: Deschide articolul selectat.
- <kbd>Esc</kbd>: Închide fereastra modală.
