# Ghid de Pornire

Bun venit în ghidul introductiv al platformei **Wildfire Docs**. În această secțiune vei învăța cum să instalezi, să configurezi și să lansezi platforma în câteva minute.

## Pași Rapizi

<Steps>
  <Step title="Verifică Cerințele Preliminare">
    Asigură-te că ai instalat Node.js versiunea 18.18 sau mai recentă și un manager de pachete (npm, pnpm sau bun).
  </Step>
  <Step title="Clonează Depozitul">
    Descarcă codul sursă de pe GitHub folosind comanda git clone.
  </Step>
  <Step title="Instalează Dependințele">
    Rulează comanda de instalare pentru a descărca pachetele necesare.
  </Step>
  <Step title="Lansează Serverul de Dezvoltare">
    Pornește instanța locală cu comanda de dezvoltare.
  </Step>
</Steps>
