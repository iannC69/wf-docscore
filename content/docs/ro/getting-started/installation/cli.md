# Utilitarul CLI

Wildfire Docs include comenzi optimizate pentru testarea statică a rutelor:

```bash
# Compilare de producție și validare TypeScript
npm run build

# Pornire server optimizat de producție
npm run start

# Verificare linting
npm run lint
```
