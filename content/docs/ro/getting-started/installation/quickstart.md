# Ghid Rapid (Quickstart)

Lansează instanța locală de documentație cu 4 comenzi simple:

```bash
# 1. Clonează depozitul
git clone https://github.com/iannC69/wf-docscore.git
cd wf-docscore

# 2. Instalează dependențele
npm install

# 3. Pornește serverul de dezvoltare
npm run dev
```

Deschide [http://localhost:3000/docs](http://localhost:3000/docs) în browser pentru a explora documentația live.
