# Cerințe Preliminare

Înainte de a instala **Wildfire Docs**, asigură-te că sistemul tău îndeplinește specificațiile minime.

## Cerințe Software

| Instrument | Versiune Minimă | Recomandat |
| :--- | :--- | :--- |
| **Node.js** | `>= 18.18.0` | `20.x LTS` sau `22.x` |
| **Git** | `>= 2.30.0` | Ultima versiune |
| **Manager Pachete** | `npm 9+` | `pnpm 9+` / `bun 1.1+` |

## Verificare Rapidă

Verifică versiunile instalate în terminal:

```bash
node -v
git --version
npm -v
```

Dacă toate comenzile returnează versiuni valide, ești gata pentru [Ghidul Rapid](/docs/ro/getting-started/installation/quickstart).
