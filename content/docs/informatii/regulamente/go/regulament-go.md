## CAP. I | REGULI GENERALE
- **1.1** Orice tentativă de trișare (folosirea de coduri, programe terțe, script-uri nepermise sau exploatarea gravă a bug-urilor) este strict interzisă și se pedepsește cu **BAN PERMANENT**.

- **1.2** Limbajul vulgar este strict interzis! De asemenea, toate conversatiile care nu au legatura cu serverul sau comunitatea pot fi discutate in privat.

- **1.3** Sanctiunile acordate pot fi
**MUTE**
**GAG**
**SILENCE**
**BAN TEMPORAR** / **PERMANENT**

- **1.4** Adresarea de injurii, atacurile personale sau lipsa de respect manifestată față de membrii staff-ului sunt strict interzise și se sancționează direct cu **SILENCE 1 ZI**.

- **1.5** Sesizările pe chat-ul adminilor (**u@**) trebuie să fie concrete și transmise printr-un singur mesaj clar (ex: "u@ Jucătorul X are aimbot"). Sunt strict interzise mesajele vagi de tip "report", precum și repetarea aceluiași mesaj (spam). Abuzul se sancționează cu **GAG**

- **1.6** Sfidarea oricarei decizii acordate de catre un membru staff este strict interzisa.
Aceasta se pedepseste cu
**MUTE**
**GAG**
**SILENCE**
**BAN TEMPORAR** / **PERMANENT**

- **1.7** Defăimarea, înjurăturile sau aducerea de ofense grave la adresa serverului sau a întregii comunități atrag după sine o sancțiune de **SILENCE 1 ZI** sau **SILENCE PERMANENT**

- **1.8** Este permisă folosirea conturilor secundare pe server. Totuși, conectarea de pe un alt cont cu scopul de a ocoli o pedeapsă activă primită pe contul principal (Ban Evading / Mute Evading) este strict interzisă.

- **1.9** Cererile de unban se fac intr-un interval de
**maximum 7 zile** de cand a fost sanctionat jucatorul.

- **1.10** **Evaziunea Sancțiunilor (Evasion):** Deconectarea intenționată de pe server (din meniu sau folosind comenzile "disconnect" / "quit") pentru a evita aplicarea unei sancțiuni (Gag, Mute, Slay) de către un membru staff este strict interzisă.
Sancțiune: Dublarea sancțiunii inițiale sau **BAN 24 ORE**

- **1.11** **Regula "S-a jucat fratele meu":** Sunteți 100% responsabili pentru orice acțiune realizată de pe contul vostru de Steam pe acest server. Scuze de tipul "s-a jucat fratele meu" sau "mi-a furat cineva contul" NU vor fi luate în considerare la cererile de unban. Ban-ul rămâne.

- **1.12** **Ban Evading:** Dacă aveți un ban activ pe un cont, este strict interzis să intrați pe server de pe un alt cont secundar pentru a juca și a ocoli pedeapsa (Ban Evade). Această acțiune atrage după sine **BAN PE IP** și aplicarea banului permanent pe absolut toate conturile folosite.

- **1.13** **Inducerea în eroare a Staff-ului:** Mințirea intenționată a unui membru staff, sfidarea repetată a răspunsurilor date pe chatul adminilor (u@) sau falsificarea de dovezi pentru a atrage sancționarea nedreaptă a altui jucător duce la **BAN 7 ZILE / PERMANENT**

## CAP. II | COMPORTAMENT PE SERVER
- **2.1** Sunt permise discuțiile libere pe voice-chat (despre gameplay, subiecte cotidiene etc.), cu condiția de a păstra bunul simț. Acestea nu trebuie să acapareze complet comunicarea audio sau să deranjeze concentrarea celorlalți jucători. În caz contrar, se va considera Mic Spam.
Sancțiune: **MUTE 10 MIN**

- **2.2** Este interzis sa stati AFK pentru farmarea de puncte/ore.
Riscati: **KICK**

- **2.3** Este strict interzisă **Metoda „Monitor”**. Aceasta presupune ca doi jucători din echipe adverse să comunice prin programe externe (Discord, TeamSpeak etc.) pentru a-și dezvălui reciproc pozițiile inamicilor.
Sancțiuni:
**KICK**
**BAN 120 MIN**

- **2.4** Pentru întrebări legate de server sau reclamarea altor jucători se folosește exclusiv chat-ul echipei cu prefixul **@ (u@)**.
Este strict interzisă folosirea chat-ului general pentru a acuza alți jucători (ex: "X are cod").
Nerespectarea acestei reguli se va sancționa cu **GAG**

- **2.5** Toxicitatea, flame-ul și instigarea la ceartă (provocările) la adresa celorlalți jucători, prin folosirea unor expresii arogante precum **"ez"**, **"culcat"**, **"sit"**, **"au măseaua"**, **"taci"** etc., sunt strict interzise.
Sancțiuni aplicabile:
**MUTE**
**GAG**
**SILENCE**

- **2.6** Pe server se comunica in limba **romana**.
Este acceptata si limba **engleza** pentru jucatorii straini.
Folosirea oricarei alte limbi atrage sanctiunea
**MUTE**
**GAG**
**SILENCE**

- **2.7** **Raportări False din Frustrare pe u@:** Sesizarea unui posibil codat pe chat-ul adminilor (u@) se face o singură dată. Este strict interzis spam-ul din frustrare doar pentru că ați fost omorât. Dacă un admin v-a răspuns că se uită, lăsați-l să-și facă treaba.
Sancțiune: **GAG 10-30 MIN**

- **2.8** **Păstrarea Liniștii la "Clutch-uri":** Dacă ești mort, ești obligat să nu faci zgomot de fundal și să nu comunici informații irelevante când colegii tăi au rămas singuri (1v1, 1v2), pentru a nu le acoperi pașii inamicilor.
Sancțiune: **MUTE**

- **2.9** **Abuzul de Bind-uri (Spam Text / ASCII Art):** Este interzisă folosirea "bind-urilor" de chat care conțin texte extrem de lungi, spam repetat la fiecare kill sau folosirea desenelor din caractere (ASCII Art) care umplu tot chat-ul serverului.
Sancțiune: **GAG** -> **BAN 120 MIN**

- **2.10** **Voice changer:** Folosirea programelor de distorsiune a vocii (Voicemod, Clownfish etc.) care transformă vocea în tonuri ascuțite, robotice sau deranjante pentru troll, este încadrată la "Mic Spam".
Sancțiune: **MUTE TEMPORAR / PERMANENT**

- **2.11** **Nume și Avatare Inadecvate:** Folosirea unui Nickname sau Avatar pe Steam care conține elemente pornografice, extremiste, naziste, rasiste sau instigatoare la ură este interzisă.
Sancțiune: Avertisment -> **KICK** -> **BAN 120 MIN**

- **2.12** **Toleranță ZERO:** Chiar dacă limbajul vulgar mai poate fi iertat, insultele rasiale (ex: N-word), extremiste, homofobe sau amenințările grave din viața reală (amenințări cu bătaia, doxxing) sunt strict interzise.
Sancțiune: **BAN PERMANENT**

## CAP. III | INTERDICTII SI RESTRICTII
- **3.1** **Scam & Trade-uri:** Orice tentativă de fraudă sau înșelăciune la schimburile de iteme (Trade) între jucătorii de pe server este strict interzisă. Cei prinși cu "țepe" vor primi direct **BAN 7 ZILE** pe server și restricție **TRADEBAN**, aplicându-se forțarea unui Revert Trade pentru returnarea bunurilor.

- **3.2** Utilizarea VPN-urilor sau proxy-urilor pentru a eluda ban-urile sau pentru a obtine avantaje nejustificate este strict interzisa.
Sanctiune: **BAN 7 ZILE**

- **3.3** Nu vă asumați rolul de membru staff dacă nu dețineți un grad. Dacă un jucător încalcă regulamentul, raportați-l pe u@. Este interzis să dați voi ordine pe chat/voice, să amenințați jucătorii sau să vă certați. Lăsați staff-ul să își facă treaba!
Sanctiune: **MUTE / GAG 10 MIN**

- **3.4** Daca un jucator ii obliga sau ii convinge pe altii sa iasa de pe server pentru a juca doar cu o anumita persoana, va primi
**SILENCE**

- **3.5** Este strict interzis sa chemati jucatorii la
**competitive / popflash / faceit / etc.**
Riscati:
**SILENCE**

- **3.6** Este interzis **griefing / troll**.
Prima sanctiune: **SLAY**

Daca se repeta: **BAN 120 MIN**

- **3.7** **Influențarea Votului (RTV / Nextmap):** Este strict interzis să forțați sau să influențați alți jucători să voteze o anumită hartă ori să dea `rtv`. Expresiile de tipul "dați rtv", "votați 1", "alegeți mirage" (pe chat sau voice) sunt interzise și se sancționează cu **SILENCE**

- **3.8** **Bomb Griefing:** Este strict interzis ca teroristul care deține bomba (C4) să o arunce intenționat în locuri de unde nu mai poate fi recuperată sau să refuze clar plantarea ei când zona este sigură.
Sancțiune: **SLAY** -> **BAN 120 MIN**

- **3.9** **Macro-uri / Scripturi:** Pe lângă "codurile" clasice, folosirea oricărui tip de Macro/Script configurat din soft-ul perifericelor pentru a realiza BunnyHop automat sau No Recoil se consideră tot o formă de trișare.
Sancțiune: **BAN PERMANENT**

- **3.10** **Cerșitul și Comerțul:** Este interzis să folosiți serverul ca piață pentru a vinde/cumpăra skin-uri sau conturi pe bani reali. De asemenea, cerșitul de VIP, grade sau skin-uri este interzis.
Sancțiune: **GAG / MUTE** -> **BAN TEMPORAR**

- **3.11** **Reclamă (Advertising):** Promovarea altor comunități, servere de Discord, servere de CS2 sau site-uri de pariuri este strict interzisă – atât prin mesaje, cât și prin folosirea link-urilor direct în nickname.
Sancțiune: Avertisment -> **KICK** -> **BAN PERMANENT**
