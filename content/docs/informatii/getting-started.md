# Ghid de Inceput pe Wildfire

Pentru a avea acces complet la comenzile de pe server (`!ws`, `!knife`, `!gloves` etc.) si a-ti pastra progresul in siguranta, este recomandat sa iti asociezi contul de Steam cu serverul de Discord.

---

## 1.0 Verificare Cont (Steam ➔ Discord)

Urmeaza acesti 4 pasi simpli pentru a-ti activa contul:

1. **Conectare pe Server:**  
   Intra pe serverul de CS2: `cs2.wildfire.ro` (sau `go.wildfire.ro`).

2. **Generare Cod Unic:**  
   Scrie comanda `!link` in chat-ul jocului.

3. **Copiere Cod:**  
   Copiaza codul unic de 6 caractere afisat in consola / chat.

4. **Validare pe Discord:**  
   Intra pe serverul de [Discord Wildfire](https://discord.gg/Knu76DhE9h) si ruleaza comanda `/verify [cod]` pe canalul dedicat de verificare.

---

## 2.0 Comenzi Esentiale pentru Jucatori

| Comanda | Descriere |
| :--- | :--- |
| `!ws` | Deschide meniul avansat de WeaponSkins pentru a-ti alege skin-ul preferat pe orice arma. |
| `!knife` | Alege modelul de cutit dorit (Karambit, Butterfly, M9 Bayonet etc.). |
| `!gloves` | Echipeaza manusi custom in-game (Sport Gloves, Driver etc.). |
| `!agents` | Alege skin-ul de personaj pentru echipele T si CT. |
| `!shop` | Cumpara culori de chat, tag-uri si personalizari cu credite castigate pe server. |
| `!cases` | Deschide cutii cu skin-uri rare si drop-uri animate direct in meci. |
| `!sl` | Joaca la aparate (Slots) cu credite sau Phoenix Coins. |
| `!rl` | Joaca la Ruleta (Roulette) pe culori si numere. |
| `!dice` | Joaca barbut (Dices) cu alti jucatori de pe server. |
| `!mvp` | Personalizeaza-ti melodia si animatia de sfarsit de runda (MVP Anthem). |
| `!missions` | Vezi misiunile zilnice active si recompensele disponibile. |
| `!rank` | Afiseaza nivelul curent de experienta, punctele si pozitia in clasament. |
