# Quickstart Guide

Get up and running with Wildfire Docs in less than 2 minutes.

## 1. Automated Clone & Install

Run the following command in your terminal:

```bash
git clone https://github.com/iannC69/wf-docscore.git
cd wf-docscore
npm install
```

## 2. Start the Dev Engine

Launch the Turbopack local dev server:

```bash
npm run dev
```

Visit [http://localhost:3000/docs](http://localhost:3000/docs) to preview your documentation hub with live hot-reloading and instant Markdown compilation.
